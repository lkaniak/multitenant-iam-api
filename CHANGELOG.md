# 1.0.0 (2026-09-22)

## Added

- Multitenant IAM API for organizations, users, roles, groups, JWT sessions, and MFA.
- Organization alerts for user, role, login, and permission events.
- A notification-service package that sends those events over HTTP.
- Coverage and scenario tests, plus a manually triggered GitHub Actions workflow.
